## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd rohit-static
```

### 3. Run Locally

Simply open `index.html` in your browser.

Alternatively, start a local Python server:

```bash
python -m http.server 5500
```

Visit:

```text
http://localhost:5500
```

No installation, dependencies, or build process required!

## 🌐 Deployment

The portfolio can be deployed easily using **Vercel**.

1. Push the project to GitHub.
2. Log in to [Vercel](https://vercel.com/).
3. Import your GitHub repository.
4. Select **Other** as the framework preset.
5. Leave the build command empty.
6. Set the output directory to `.`.
7. Click **Deploy**.

Your portfolio will be live!

## ⚙️ Customization

| What to Edit | File / Location |
|---|---|
| Personal information | `index.html` |
| Projects | `script.js` → `projects` array |
| Certifications | `script.js` → `certs` array |
| Styling and animations | `style.css` |
| Resume | `assets/resume/` |
| Profile and other images | `assets/` |

### 📬 Contact Form

The current static implementation uses `mailto:` to open the visitor's default email client.

For direct form submissions without a backend, integrate [EmailJS](https://www.emailjs.com/) and update the submit handler in `script.js`.
